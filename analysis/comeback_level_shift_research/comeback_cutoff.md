# Comeback-hold cutoff (Experiment B2/B3)

Generated by `exp_cutoff.py` on the October 15 champion replay. The hold removes rows and never changes a projection, so on pickups two cutoffs both score their accuracy is identical by construction. What differs is coverage. The table reports the pickups each cell withholds and the error their projection would have had, never a zero error. *Scored WAPE* moves only because the scored set changes. It is not a model improvement.

High-volume = at least 1344 gal in the 365 days before the GAP began (the top quartile of trailing-year gallons over all scored pickups). Seasonal = a closer, or a return classified as a reopening.
