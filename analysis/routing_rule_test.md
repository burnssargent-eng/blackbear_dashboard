## Caveats

- **Customer scores use the test years.** Each holdout customer's repeatability is computed from 2023–25, the years its pickups are scored on. The customers are out of sample; the classification is not. A production version would score each customer from history before the prediction.
- **Lower-volume customers are noisier.** Most of the holdout produces 500–1,000 gallons a year, so expect higher error across the board than the steady sample.
- **The bootstrap treats pickups as independent,** so true intervals are somewhat wider.
